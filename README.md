# 重置价值计算器

一个无需后端的静态网页，用剩余周额度、使用重置的时间和原自然重置时间，估算重置的净价值，并对比两种情况下的额度变化。

[在线使用](https://chentyke.github.io/reset-value-calculator/)

## 本地运行

需要 Node.js 18 或更新版本。项目没有运行时或构建时第三方依赖。

```sh
npm ci
npm test
npm run build
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。部署时将 `dist/` 作为静态网站目录；每次修改 `src/` 后重新执行 `npm run build`。

推送到 GitHub 仓库的 `main` 分支后，Pages 工作流会先运行测试和构建，再发布 `dist/`。

## 估算方法

设剩余周额度为 `r`（0 到 1），使用重置到原自然重置的间隔为 `h` 小时（0 到 168），套餐月价为 `p` 美元。网页显示的净值为：

```text
补回额度价值 = (1 - r) × p × 7 / 30
自然重置延期成本 = (168 - h) / 24 × p / 30
净值 = 补回额度价值 - 自然重置延期成本
```

图表为均匀消耗额度的示意图。该模型假设补回的额度能够用满，且使用重置后重新开始 7 天周期；负净值会照常显示。价格是页面中的固定预设，使用前请核对最新套餐价格和实际重置规则。计算器不读取账户信息，也不判断当前账户是否有资格使用重置。

## 代码结构

- `src/`：网页、计算逻辑、图表和时间输入的源文件。
- `scripts/build.cjs`：将源文件复制到静态发布目录 `dist/`。
- `*.test.cjs`：计算、日期和图表几何检查。

这是独立的估算工具，与 OpenAI 没有隶属关系。
